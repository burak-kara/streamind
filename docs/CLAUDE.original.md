# Docs Folder Guide

This file maps the `docs/` directory for agent navigation. Start here when looking for specs, plans, or reference material.

## Challenge

- `CHALLENGE.md`: Full challenge specification — scoring formula, endpoint contract, submission format
- `images/challenge_overview.png`: Pipeline architecture diagram
- `images/challenge_scoring.png`: Scoring breakdown diagram
- `datasets/`: Audio transcription datasets, details and links. Do not index or include in the context.

## Task Tracking

- `TODO.md`:  Active task list with checkable items — read before starting new work

## Plans

Archived implementation plans in `plans/`. These are historical records of completed or in-progress design decisions — useful for understanding *why* something was built a certain way.

- `plans/latency-optimization-and-format-fixes.md`: Latency reduction and challenge output format fixes
- `plans/graceful-drifting-kettle.md`: Implementation plan (see file for details)
- `plans/piped-tumbling-glade.md`: Implementation plan (see file for details)
