Why and how¶

We believe the most effective way of learning how a tool works is using it. This is why we decided to offer a set of documentation pages aimed at offering practical insights for the most common tasks involved in the development of custom components and pipelines.

You will see:

  • how to design and create custom nodes using the simple functionalities included in juturna

  • how to create full pipelines to deploy locally

  • how to work with environment variables to have a better grip on the juturna internals

  • how to deploy components remotely and use them as if they were local

  • how to use the CLI tools offered by juturna

  • how to observe juturna pipelines
